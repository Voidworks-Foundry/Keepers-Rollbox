# Shortcuts

[← Back to the guide](README.md)

**For:** everyone. Every click and key Rollbox answers, in one place.

Rollbox shows no tooltips for these: this page is where to look them up. They follow CoC7's own character sheet shortcuts, sent through Rollbox's flyouts. **Ctrl** is Ctrl, or Cmd on a Mac. **Alt** is Option on a Mac. "Sends at once" works like the flyout's send button: the player gets the request, and an NPC is rolled for you; on a player's panel it makes their own check. CoC7's Ctrl shortcuts copy a roll link; Rollbox copies no links, so on the character sheet Ctrl + click works as a plain click, and on a Check row it does nothing.

## The character sheet's values

The eight characteristics, SAN and Luck on the character sheet. On the two-character sheet, each number is that character's. HP, MP and the character cards' values don't take clicks. On a player's panel SAN does nothing (players have no Sanity tab), Luck needs the Luck feature, and Shift + click rolls their own check at once, Regular, with no window.

| Click | A characteristic (STR … EDU) | SAN | Luck |
| --- | --- | --- | --- |
| Click | Check, only this ticked (if Check is open, the tick moves here) | Check, Sanity tab | Other, Luck tab |
| Shift + click | Sends a Regular check at once (no dice, not Blind, no label). While an opposed roll waits for a side, fills that side and makes the card | Sends CoC7's plain SAN roll at once (no loss) | Sends a plain Luck check at once |
| Ctrl + click | As a plain click | Check, Sanity tab | Other, Luck tab |
| Shift + Ctrl + click | As a plain click | Check, Sanity tab | Other, Luck tab |
| Alt + click | Nothing | Check, Sanity tab | Nothing |
| Right click | Opens [Opposed](opposed.md) with this character as the first side | Check, Sanity tab | Other, Luck tab |
| Shift + right click | The same, and the opposed card is made as soon as both sides have a check | Check, Sanity tab | Other, Luck tab |
| Alt + right click | Check, with this added to the ticks already there (a [combined check](check.md#combined-checks)) | Check, Sanity tab | Other, Luck tab |
| Shift + Alt + right click | Adds this to the ticks and sends at once, with the flyout's All/Any choice and options | Check, Sanity tab | Other, Luck tab |
| Ctrl + right click | Nothing | Check, Sanity tab | Nothing |

A right click on these values never opens the browser's menu. Ctrl + Alt + right click on a characteristic works as Alt + right click. SAN and Luck are never part of an opposed or combined roll, so those shortcuts open their own place.

## Check flyout rows and tiles

| Click | Does |
| --- | --- |
| Click | Ticks or unticks it |
| Shift + click | Sends just this check now (Regular, no options) |
| Ctrl + click | Nothing |
| Ctrl + Shift + click | Ticks or unticks it |
| Alt + click | Nothing |
| Right click | Opens Opposed with it as the first side (with one or two characters selected). A player not allowed Opposed rolls reads "You can't start an opposed roll." |
| Shift + right click | The same, and the opposed card is made as soon as both sides have a check |
| Alt + right click | Adds it to the ticks |
| Shift + Alt + right click | Adds it and sends the ticks now |
| Ctrl + right click | Nothing |
| Ctrl + Alt + right click | Adds it to the ticks, as Alt + right click (Alt counts first, as on CoC7's sheet) |

A player without **Combined checks** ticks one check at a time: a tick, or Alt + right click, replaces the one already ticked.

## The panel

| Click or key | Does |
| --- | --- |
| Click a menu button | Opens its flyout; click again to close it |
| Click a row of the players list (Keeper, nothing selected) | Selects that investigator's token |
| Drag the header (the name row, or "N selected") | Moves the panel, with **Allow moving the panel** on |
| Click the portrait's **×** on a character card, on either portrait of the two-character sheet, or on the one-character sheet (Keeper) | Deselects that token (the others stay selected) |
| Click a character card anywhere but its **×** (Keeper, three or more selected) | Selects only that character |
| Right click a character anywhere in Rollbox: the character sheet (not on a value), a character card, the players list, the turn order, the joining card, Opposed's sides, Assist's rows (Keeper and players) | Makes them your target, as a click on their token with Foundry's Target tool |
| Escape, while a flyout is open | Closes the flyout, with **Escape closes the flyout** on (the default) |
| Click the button on the character sheet's header | Opens the character's full sheet |
| Click the panel | Brings it to the front, with Panel layer **Top when active** |
| Click the **×** on a Restrained status card (Keeper) | Clears Restrained |

## Typing

| Key | Where | Does |
| --- | --- | --- |
| Enter | The skill search box | Adds the typed skill when the list shows "+ Add" |
| Enter | A value line (a Sanity loss, improvised damage, the number to beat) | Confirms it; clicking away does the same |

## Turn controls

Delay, Flee, Leave out, End turn (End my turn) and End combat each ask once: the first press turns the button red ("Confirm …"), the second acts. Delay's ← and → move the character up or down the order before Confirm delay.

## Keys Rollbox doesn't take

Rollbox handles no keys outside its own text boxes but **Escape**, which closes an open Rollbox flyout while the personal setting **Escape closes the flyout** is on (the default); with no flyout open, or the setting off, Escape does whatever Foundry does with it. **Tab** never stops on its buttons or values. Foundry's own keys still work: **T** targets the token under the mouse.
